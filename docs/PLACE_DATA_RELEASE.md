# 배포 장소 데이터와 동반 확인 결과

기준 시각: 2026-11-18 22:06 KST. 아래 건수는 해당 검증 시점의 스냅샷이며,
이후 운영자 보정·숨김, 사용자 선택과 지도 범위에 따라 API 결과가 달라질 수 있습니다.

## 보관과 노출

| 출처 | DB 보관 | 지도 노출 대상 | 처리 |
| --- | ---: | ---: | --- |
| 팀이 직접 조사한 실제 장소 | 41 | 41 | 카페 25·음식점 16, 원문 조건과 좌표 근거 보존 |
| 한국관광공사 서울 공공 장소 | 3,159 | 997 | 공식 동반 상세 확인, 나머지 2,162곳 비노출 |
| 시연용 가상 업체 | 6 | 4 | 동반 미확인·동반 불가 업체 2곳은 관리 데이터만 유지 |
| 합계 | 3,206 | 1,042 | 화면에 동시에 표시되는 핀 수와는 다름 |

목록에 포함됐거나 `visible=true`라는 사실만으로 동반 가능을 가정하지 않습니다.
동반 가능이 확인된 장소만 지도·검색·상세·챗봇 후보에 포함합니다. 회색은 **동반 가능은
확인됐지만 반려견별 입장 판정에 필요한 세부 조건이 부족한 상태**입니다.
동반 자체가 미확인이거나 동반 불가인 장소는 노출하지 않습니다.
확인된 체중 제한을 위반하면 나머지 조건이 미확인이어도 입장 불가입니다.

공공데이터 공식 상세 API의 HTTP 429 호출 제한으로 나머지 2,162곳의 동반 상세 확인은
끝나지 않았습니다. 오류·미수집을 동반 불가로 확정하지 않으며, 원본을 보관하고 노출을
보류합니다. 재확인 시 공식 API 호출 제한과 이미 수집한 캐시를 먼저 확인해야 합니다.

## 실제 팀 조사 장소

[41곳 전체 이름·주소·DB ID·원문 조건·좌표 근거](TEAM_RESEARCH_PLACES.md)를 확인합니다.
`PUBLIC:6321`부터 `PUBLIC:6361`까지의 ID는 이 배포 환경의 실제 입력 결과이며,
새 환경에서 같은 ID를 가정하면 안 됩니다. 입력 스크립트는 출처와 노션 페이지 ID로 재사용합니다.

- 기름칠·빌라드블루 성수의 `7kg 미만`은 엄격한 상한으로 저장했습니다. 정확히 7kg도 제한 대상입니다.
- 단일 준비물로 명확한 8곳만 필수 준비물로 구조화했습니다.
- 다중 선택 준비물의 AND/OR, 구체적인 백신·제한 견종은 추측하지 않고 원문과 미확인 상태로 보존합니다.
- 빈 필드는 제한 없음이 아닙니다. 원문에 `없음`이 있는 조건과 구분합니다.
- 실제 장소의 업체 계정·소유자 인증을 임의로 생성하지 않았습니다.
- 40곳은 카카오맵의 업체명과 주소를 대조했고, 백야드빌더 HQ는 정확한 건물 주소의 OSM 좌표를 사용했습니다.
  해당 좌표 출처는 © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright)입니다.

## 검증한 내용과 한계

| 검증 | 결과 |
| --- | --- |
| 실제 장소 41곳의 상세 API | 몽이 5kg 기준 동반 확인·부분 정책·회색 판정 확인 |
| 실제 장소별 좌표 30m 지도 조회 | 41곳 전부 해당 카테고리와 함께 조회 |
| 업체명 검색과 카테고리 필터 | 41곳 전부 조회 |
| 성수 37.5446, 127.0557, 반경 1.5km | 몽이 기준 68곳 반환 |
| 동반 자체가 미확인·불가인 장소 | 상세 404 및 지도 비노출 확인 |
| 배포 DB 재입력 | 1,038개 근거 연결의 장소 ID 유지, 신규 중복 없음 |
| 기존 데이터 보존 | 사용자 33·반려견 3·업체 6·방문 31·스탬프 26 유지 |
| 최종 배포 | 로그인·장소 상세·지도·health 200 재확인 |

현재 지도 API는 반경·위치·카테고리·선택 반려견에 따라 결과가 달라지고 최대 500곳을 반환합니다.
68곳이나 1,042곳을 프론트에 상수로 넣지 않습니다. 회색 정책은 반려견의 제한 위반 여부에 따라
빨강이 될 수 있으므로 몽이 검증 결과를 모든 반려견의 결과로 일반화하지 않습니다.

기존 사용자 데이터는 유지했으며 시연 초기 상태로 강제 초기화하지 않았습니다. 재시연 전에
반려견 목록과 정책·방문 상태를 조회합니다. 전체 `reset`을 장소 추가 수단으로 사용하지 않습니다.

## 실행 순서

실행 가능한 세부 계약은 [동반 근거 입력 가이드](confirmed-admission-import.md)와
[시연 시드 가이드](DEMO_SCENARIO.md)를 참고합니다.

1. V23 이상과 API·대상 DB를 확인하고 기존 출처 ID·운영자 보정·숨김을 조회합니다.
2. 팀 원문·검증된 건물 좌표·공식 동반 상세 캐시를 준비합니다. 전체 목록 수집은 근거 수집과 분리합니다.
3. 백업 저장 위치와 출처 중복 후보를 확인한 뒤 별도 스크립트를 명시적으로 실행합니다.
4. 생성·재사용 ID, 노출 대상, 원문 조건과 출처를 대조합니다.
5. 보호자 API로 상세·지도·검색·미확인 비노출을 확인하고 기존 사용자 이력 보존을 확인합니다.
6. 재실행 후 동일 출처 ID가 유지되는지 확인하고 임시 연결값 파일을 삭제합니다.

```sh
python3 scripts/import_admission_evidence.py --apply --env-file <권한 제한 임시 연결 파일>
```

이 명령은 실제 DB 입력 명령입니다. 앱 시작이나 배포 시 자동 실행하지 않습니다.
원본·백업·계정 파일은 `.demo/`에서 별도로 관리하며 저장소에 올리지 않습니다.
이 문서에는 DB 접속값·계정 비밀번호·API 키·QR 원본 토큰을 포함하지 않습니다.
