# 운영자 접종 서류 열람

`GET /api/v1/admin/vaccination-records/{recordId}`는 OPERATOR에게만 원본의 만료되는 열람 URL을 제공합니다.
기존 `recordId`, `dogId`, `status`, `documents`, `items`는 유지하며 다음을 추가합니다.

- `dog`: 반려견 이름·견종·체중
- `documents[].url`, `contentType`, `urlExpiresAt`: 이미지/PDF 원본 열람
- `documents[].readError`: 서명 주소 발급 실패 시 첨부는 유지하고 재조회를 안내

URL은 DB에 영구 저장하지 않고 요청할 때마다 발급합니다. 파일 경로는 서버에 저장된 문서에서만 읽으며 임의 경로를 요청받지 않습니다.
보호자·업체 계정은 운영자 상세로 파일 주소를 발급받을 수 없습니다.

목록의 기본 범위는 기존 검토 대기 상태이며, `status=VERIFIED` 또는 `REJECTED`로 처리된 기록도 확인할 수 있습니다.
완료 기록 조회가 허용되어도 처리 API의 검토 가능 상태 제한은 유지됩니다.

프론트는 AI·GUARDIAN·OPERATOR 항목을 구분하고 백신 코드와 날짜를 함께 유지합니다.
확인 완료 요청에는 운영자가 서류와 대조한 백신 코드·날짜 목록을 전달해 실제 확정 항목으로 저장합니다.
보호자 개인정보나 미추출 병원명, 존재하지 않는 제출일은 만들어 넣지 않습니다.

현재 DB 스키마는 원본 파일명을 저장하지 않으므로 문서 번호로 식별합니다.
삭제된 반려견·접종 기록은 열람 코드로 복구되지 않습니다. 서류가 실제로 없는 경우에는 다시 등록·업로드해야 합니다.
