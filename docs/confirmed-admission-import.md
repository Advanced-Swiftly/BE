# 반려견 동반 확인과 지도 노출

지도·검색·상세에는 반려견 동반이 명시적으로 확인된 장소만 노출합니다.
`public_facility.visible=true`만으로는 충분하지 않습니다.
공공 장소에는 확인일이 도래한 `place_entry_policy.pets_allowed=true`가 필요합니다.
업체 장소는 현재 적용 중인 승인 정책과 공개·인증 상태를 확인합니다.

회색 `CHECK_REQUIRED`는 동반은 가능하지만 반려견별 입장 판정에 필요한 조건이
부족하다는 의미입니다. 동반 여부 자체가 미확인이거나 동반 불가인 장소는 제외합니다.
체중 등 확인된 제한을 위반하면 조건 일부가 미확인이어도 입장 불가입니다.

V23은 부분 정책의 `details_complete=false`와 엄격한 체중 상한의
`max_weight_exclusive=true`를 지원합니다. 상세 API는 `admissionConfirmed`,
`policyDetailsComplete`, `maxWeightExclusive`를 제공합니다.
부분 정책의 빈 조건을 제한 없음으로 반환하지 않습니다.

## 별도 입력

일반 KTO 목록 수집은 동반 확인 근거가 아닙니다. 공식 `detailPetTour2`의 동반 유형이나
팀이 직접 조사한 근거를 별도로 확인합니다. 오류·429·빈 응답은 동반 불가 판정도,
동반 가능 근거도 아닙니다. 미확인 원본은 보관하되 지도에 노출하지 않습니다.

`scripts/import_admission_evidence.py --apply --env-file <임시 연결 파일>`은
V23 이후에만 수동 실행합니다. `.demo`의 검토된 팀 조사 원본·좌표·공식 동반 상세 캐시를
입력으로 사용하고, 입력 전 백업 및 결과 ID 목록을 저장합니다. 앱 시작 시 실행하지 않습니다.
팀 자료는 `TEAM_RESEARCH` 출처와 노션 페이지 ID를 사용하여 재실행 중복을 방지합니다.
팀 조사와 좌표 확인 출처는 `public_facility.admission_evidence`에 보존합니다.
기존 운영자 수정·숨김 및 기존 정책은 덮어쓰지 않습니다.

준비물 다중 선택의 AND/OR 의미, 백신의 구체 종류, 제한 견종 목록은 추측하지 않습니다.
원문에 보존하고 조건 미확인으로 처리합니다. 단일 준비물 및 `7kg 미만`처럼 명확한
조건만 구조화합니다. 팀이 확인한 장소에 업체 소유권이나 계정을 임의 생성하지 않습니다.

좌표는 업체명·주소를 지도와 대조하며, 건물 위치가 확인되지 않은 도로/동 중심 좌표는
사용하지 않습니다. OSM 좌표를 사용하는 경우 © OpenStreetMap contributors, ODbL 1.0
출처를 원문과 결과 문서에 함께 보존합니다.
